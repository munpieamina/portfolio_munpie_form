# Публикация munpie на Vercel и отправка заявок в Telegram

## 1. Создать бота
1. В Telegram открыть **@BotFather**, отправить `/newbot`, задать имя и username бота.
2. BotFather выдаст **токен**. Его нельзя публиковать в GitHub, index.html или script.js.
3. Перейти к новому боту, нажать **Start** и отправить ему любое сообщение, например `test`.
4. В адресной строке браузера открыть `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates` (вставить токен вместо `ВАШ_ТОКЕН`). В JSON найти `result` → `message` → `chat` → `id` — **ID своего чата**, не ID бота. Если `result` пустой, сначала отправить сообщение боту; при работающем webhook getUpdates может быть недоступен. Не делиться ссылкой с токеном и не делать скриншоты с ним.

## 2. Опубликовать сайт
1. Создать GitHub-репозиторий, загрузить в него **содержимое папки portfolio** (index.html, style.css, script.js, api/, images/, package.json), так чтобы index.html и api/ лежали в **корне репозитория**.
2. Войти на https://vercel.com → Add New → Project → импортировать репозиторий GitHub.
3. Framework Preset: **Other**; Root Directory: `./` (если содержимое portfolio уже в корне); Build Command не задавать, Output Directory оставить по умолчанию.
4. Перед Deploy либо после него в Settings → Environment Variables добавить:
   - `TELEGRAM_BOT_TOKEN` = токен от BotFather
   - `TELEGRAM_CHAT_ID` = числовой chat.id из getUpdates
   Обе переменные указать для **Production**.
5. Нажать Deploy (или **Redeploy** после добавления переменных). Получить ссылку `https://...vercel.app`.
6. Открыть ссылку, найти блок «Обсудим проект?», заполнить и отправить тестовую заявку. Проверить, что бот прислал сообщение в личный чат.

## Что делает код
- index.html: поля формы, метод POST, чекбокс согласия.
- style.css: оформление под дизайн портфолио.
- script.js: проверяет заполнение и отправляет JSON через fetch на `/api/send`.
- api/send.js: серверный JavaScript (Vercel Function) валидирует заявку и отправляет её в Telegram методом sendMessage. Секреты находятся только в переменных окружения.

## Важно
- Открытие index.html двойным щелчком показывает форму, но **не запустит** `/api/send`. Для отправки нужен деплой на Vercel или локальный `vercel dev`.
- Бот не является базой данных; заявки сохраняются в истории чата, пока сообщения там существуют.
- Для реального публичного сайта дополнительно стоит сделать полноценную политику обработки данных, антиспам/rate-limit и оценить применимые требования по персональным данным. Для лабораторной используйте вымышленные тестовые данные.
- Если увидите «Отправка пока не настроена», проверьте переменные среды и Redeploy; если «Не удалось доставить заявку», проверьте chat.id, токен и то, что боту написали `/start`.
- Не отправляйте токен даже преподавателю: для проверки достаточно ссылки на сайт и скриншота сообщения бота без секретов.
